# CareFlow frontend

React + TypeScript (Vite) app with two role-based views served by the FastAPI backend:

- Patient portal: chat with streamed progress events, confirmation cards, conversation history, care plan and appointments panel.
- Coordinator console: priority queue, approve / deny / answer actions, patient timeline, care-plan progress.

The app is scaffolded in Milestone 2 (chat) and extended in Milestone 6 (console).
